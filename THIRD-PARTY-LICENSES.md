# Third-party code

## js-mp3 (js/js-mp3.vendor.js)

Pure JavaScript MP3 decoder used when the host app can not decode MP3 itself. Bundled unmodified (minified with esbuild).

- js-mp3 0.1.0, MIT, https://github.com/soundbus-technologies/js-mp3
- It is a port of go-mp3 (Apache-2.0, https://github.com/hajimehoshi/go-mp3), which is based on PDMP3 (public domain, https://github.com/technosaurus/PDMP3).
